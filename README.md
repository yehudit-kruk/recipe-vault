# מתכון (RecipeVault)

מערכת לניהול מתכונים אישיים: כתיבה ידנית, ייבוא מצילום או מקובץ עם חילוץ אוטומטי,
חיפוש וסינון. הממשק בעברית ובכיוון RTL.

> 🚧 הפרויקט בפיתוח. ההתקדמות מתועדת ב־[docs/log.md](docs/log.md)

## סטאק
- **קליינט:** React, TypeScript, Vite, Tailwind
- **שרת:** ASP.NET Core Web API, EF Core
- **בסיס נתונים:** PostgreSQL
- **סביבה:** Docker Compose, GitHub Actions

## מבנה התיקיות
| תיקייה | תוכן |
|---|---|
| `api/` | שרת ASP.NET Core |
| `client/` | אפליקציית React |
| `docs/` | אפיון, יומן עבודה ומסמכי תכנון |
| `docs/design-reference/` | מסכי עיצוב וצילומי ייחוס |
| `docker/` | קבצי Docker וסביבת הרצה |
